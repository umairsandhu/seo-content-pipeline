Why it's different

99% of SEO work is diagnosis without execution

Audits, spreadsheets, and briefs that someone else has to implement. This tool collapses that gap. It lives where the work happens — the codebase and the data — and runs the whole loop end to end:

Diagnose→Decide→Produce→Ship→Measure→Learn↻
It ships the fix, not a description

Every finding becomes a real change — a git PR that edits meta/schema/redirects, a CMS update, or a browser action — gated by your approval.

It proves what worked

A causal change ledger logs every change and attributes the outcome — before→after clicks & position vs a holdout of untouched pages. No human does this rigorously.

Expert-grade by design

Outputs are written by named personas — a McKinsey-caliber strategist, a top technical SEO, an E-E-A-T content writer — not a generic model.

Built for the AI-search era

Tracks your citation share in ChatGPT / Perplexity / Gemini / Google AI Overviews, and optimizes entity + passage-citability to win it.

The moat: that closed loop — execution + change-level attribution — is the thing SaaS dashboards and human consultants structurally can't do. It compounds into a proprietary "what actually works on this site" dataset that sharpens every future decision.
Capabilities

One engine, the whole SEO lifecycle

Technical Doctor

JS-rendered crawl, Core Web Vitals, canonical/redirect/orphan/hreflang checks, sitemap & robots hygiene, structured-data generation + validation, log-file crawl-budget & AI-crawler coverage. Every finding ships a diff.

Strategy Brain

Topical-authority map, cannibalization → 301 plan, striking-distance keywords, internal-PageRank sculpting, competitor content & backlink gaps, and monthly competitor sitemap-deltas.

Content Studio

SERP-grounded briefs and full drafts, decaying-page refreshes, title/meta rewrites — written by a multi-agent crew (research → strategy → write → edit → tech-SEO).

AI-Search / GEO

AI-visibility tracker (mentions + citations + share-of-voice across ChatGPT/Perplexity/Gemini/AI Overviews), entity graph + Wikidata, passage-citability scoring.

Site Control

Full CRUD via repo PRs, WordPress/Webflow/Ghost APIs, or headless-browser automation — create, update meta/content, delete, redirect. Every change autonomy-gated and logged.

Reporting & Attribution

Daily/weekly/monthly digests, causal ledger with holdout attribution, GA4 organic revenue, decay radar, and anomaly alerts (indexation drops, CWV regressions, an AI Overview appearing).

Safe by design. A programmatic-content safety gate hard-blocks thin / near-duplicate / boilerplate pages before publish (Google's 2026 scaled-content enforcement). Nothing ships without passing the gate and your autonomy mode.
Quick-start manual

From zero to a shipping loop

1

Install

Python 3.11+. Core is numpy + scikit-learn; every API is optional.

# as a standalone CLI $ pip install numpy scikit-learn $ git clone <repo> && cd <repo> # …or drop it in as a Claude Code skill, or run: python -m seo_agent mcp
2

Create a workspace (one folder = one site)

$ python -m seo_agent init --site https://your-site.com $ python -m seo_agent wizard # guided, hand-holding setup

The wizard walks you through every step with ✅/▶/○ status and the exact next action.

3

Wire the data (the readiness gate blocks until you do)

$ python -m seo_agent preflight # 0–100 readiness score # Search performance: a GSC service account, or import an export: $ python -m seo_agent gsc --csv export.zip # Market data: DATAFORSEO_LOGIN / DATAFORSEO_PASSWORD in .env (or Semrush/Ahrefs)

Optional: PageSpeed key, GA4, Slack/WhatsApp channels, email transport — each unlocks more. Nothing required to start.

4

Baseline & get the plan

$ python -m seo_agent onboard # → BASELINE.md (audit + speed + gaps + AI-search) $ python -m seo_agent plan # ranked "what to do next" $ python -m seo_agent consult # board-ready growth strategy
5

Choose how much it may do on its own

Set autonomy: manual (plan only) · approve (queue → you sign off) · auto (execute, with destructive changes still queued).

6

Ship fixes & content — with human review

$ python -m seo_agent audit --fix # audit + PR-ready remediation plan $ python -m seo_agent pr fixes.json # edit repo files → open a PR $ python -m seo_agent crew article "keyword" # multi-agent draft → gated publish $ python -m seo_agent review # send to reviewers (Slack/WhatsApp/email) $ python -m seo_agent apply --approved # push ONLY approved items

Reviewers reply APPROVE 3 or CHANGES 3 make it punchier from any channel. Only approved changes ship.

7

Run on a cadence & deliver

$ python -m seo_agent run --daily --email # pulse + auto-email the PDF $ python -m seo_agent run --monthly # full digest + AI-search + backlink gap $ python -m seo_agent anomaly --alert # regressions → your channels

Schedule via cron or the hosted scheduler. Reports go to email, Slack, or Mattermost.

8

Measure & ask why

$ python -m seo_agent ledger # every change → holdout-adjusted lift $ python -m seo_agent explain /pk/lawn-suits # "why did this page drop?"

explain correlates a decline against our own change log, the GSC trend, and the Google-update timeline — evidence, not correlation theater.

How & where it runs

Your stack, your rules

Three runtimes, one engine

Claude Code skill · any MCP client / agent runtime · standalone CLI (cron). A hosted web app is planned — a thin wrapper over the same engine.

Human-in-the-loop by default

Nothing structural ships without review. Approve from CLI, email, Slack, Mattermost, or WhatsApp. Autonomy is a dial you control per site.

Your data stays yours

File-based, per-workspace. No central warehouse of Google/DataForSEO data — a compliance feature, not a limitation.

Fork-safe secrets

Keys live in a git-ignored, leak-scanned .env. They can never leak from a fork — enforced before anything else runs.
